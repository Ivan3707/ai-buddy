Расширение «Бади» для Chrome

Установка из магазина пока не настроена: эта страница имитирует её для демо.

С расширением Бади живёт на любой странице: подсказывает по открытой вики или Grafana, разбирает выделенный текст, сообщает о статусе заявок. Вход общий с сайтом.

Как поставить сейчас (вручную)

  1. Возьмите папку apps/extension/dist из сборки проекта (npm run build --workspace @ai-buddy/extension).
  2. Откройте chrome://extensions и включите «Режим разработчика».
  3. Нажмите «Загрузить распакованное расширение» и выберите папку dist.
  4. Закрепите значок AI-buddy и обновите сайт: знак «⚠ Нет расширения» в чате Бади исчезнет.
