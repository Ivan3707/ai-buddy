Расширение «Бади» для Chrome

Демо-версия для прототипа AI-buddy. Chrome 116+ (или Edge, Яндекс Браузер на Chromium).

С расширением Бади живёт на любой странице: подсказывает по открытой вики или Grafana, разбирает выделенный текст, сообщает о статусе заявок. Вход общий с сайтом.

Скачать расширение (.zip)

Как установить (1 минута)

  1. Распакуйте скачанный архив в отдельную папку, например ai-buddy-extension.
  2. Откройте chrome://extensions и включите «Режим разработчика» (переключатель справа вверху).
  3. Нажмите «Загрузить распакованное расширение» и выберите эту папку (в ней лежит manifest.json).
  4. Закрепите значок AI-buddy и обновите эту вкладку: знак «⚠ Нет расширения» в чате Бади исчезнет, вход подхватится с сайта.

Где попробовать

Демо-страницы «корпоративных сервисов»: вики, Grafana, Jira. На вики выделите «нужно минимум 2 одобрения» и спросите Бади «это ещё актуально?».

Магазина расширений у прототипа нет, поэтому установка ручная. Архив собран под адрес этого сайта: запросы идут на тот же сервер, что и сайт.
