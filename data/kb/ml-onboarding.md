## Окружение
Эксперименты запускают в JupyterHub на кластере команды. Квота на стажёра — одна GPU до 8 часов в сутки. Локально на ноутбуке обучать модели на рабочих данных нельзя.

## Эксперименты
Каждый эксперимент логируется в MLflow: параметры, метрики, ссылка на коммит. Название эксперимента: <команда>/<задача>/<описание>.

## Данные
Данные для обучения берутся из витрин в Redash и Hive. Доступ к витрине запрашивается заявкой с уровнем read у владельца витрины.

## Первая задача
Типичная первая задача ML-стажёра — воспроизвести baseline модели рекомендаций: собрать датасет из витрины, обучить модель по README репозитория recsys-models, сравнить метрики с опубликованными и залогировать в MLflow.
