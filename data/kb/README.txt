Синтетическая база знаний AI-buddy (ДЕМО). Не является регламентами Авито или другой реальной компании.
Формат: один документ = один .md с front matter (id, title, url, updated); разделы "## " режутся на фрагменты для поиска.
Намеренно заложено для eval:
- противоречия: leave vs first-week (срок отгула), git-workflow vs code-review (число аппрувов);
- непрямая prompt injection: wiki-faq (страница, которую редактируют сотрудники).
