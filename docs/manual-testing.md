# Ручная проверка: все сценарии стажёра и наставника

Чек-лист, чтобы пройти продукт руками и увидеть каждую фичу. У каждого шага указано, что делать, что должно получиться и какую фичу он проверяет.

> Всё проверяется на настоящем стеке: React-веб и расширение ходят в Go-backend, он — в AI-сервис. Данные синтетические.

## 0. Подготовка

1. **Стенд.** `cp .env.example .env`, в `.env` задать `LLM_*` (см. README, «Подключение LLM»), затем `docker compose up -d --build --wait`. Сервис `init` сам применит миграции, загрузит чек-листы, создаст демо-аккаунты и демо-данные. Web: <http://127.0.0.1:5173>. Чтобы начать заново: `docker compose down -v` и снова `up`.
2. **Учётки.** Пароль у всех `AiBuddy2026`. Основные: `ml.intern@demo.example` (стажёр ML, у него уже есть задача на проверке, заявка и вопрос наставнику), `buddy@demo.example` (наставник), `teamlead@demo.example` (руководитель). Остальные описаны в README.
3. **Чат стажёра на сайте:** войти как `ml.intern@demo.example` и нажать на Бади в правом нижнем углу. Это тот же виджет, что в расширении.
4. **Расширение.** Собрать: `docker compose -f compose.test.yaml run --rm extension`. Затем `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → `apps/extension/dist`. Бади появится в правом нижнем углу любого сайта, вход общий с сайтом.
5. **Кабинет наставника:** во втором окне (инкогнито) войти как `buddy@demo.example`, раздел «Вопросы». Список обновляется сам каждые 15 секунд.

**Демо-профиль стажёра** берётся из БД: этап, активная задача, задачи на проверке и замечания наставника из чек-листов `ml.intern@demo.example`.

**Резервная локальная модель (A7, по желанию).** Ollama с `qwen3.5:4b` уже стоит. В `.env` прописать:
```dotenv
LLM_FALLBACK_BASE_URL=http://host.docker.internal:11434/v1
LLM_FALLBACK_MODEL=qwen3.5:4b
LLM_FALLBACK_EXTRA_BODY={"reasoning_effort":"none"}
```
Затем:
1. Временно испортить `LLM_BASE_URL`.
2. Пересоздать ai: `docker compose -p ai-buddy up -d ai`.
3. Задать вопрос по базе. Ответит локальная модель (первый раз 10–20 с, пока она загружается). Действия у неё ненадёжны: это известное ограничение, см. `apps/ai/eval/reports/local-models.md`.
