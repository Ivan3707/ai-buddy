# Ручная проверка: все сценарии стажёра и наставника

Чек-лист, чтобы пройти продукт руками и увидеть каждую фичу. У каждого шага указано, что делать, что должно получиться и какую фичу он проверяет.

> Всё проверяется на настоящем стеке: React-веб и расширение ходят в Go-backend, он — в AI-сервис. Данные синтетические.

## 0. Подготовка

1. **Стенд.** В `.env` должны быть заданы `LLM_*` (OpenRouter). Стенд поднимается по README: Postgres, миграции goose (включая `00002_assistant`), `bootstrap` (каталог чек-листов и синхронизация Mock HR), затем
   ```sh
   docker compose -p ai-buddy up -d --build --wait
   ```
   Должны подняться: web `http://127.0.0.1:5173`, backend `http://127.0.0.1:${BACKEND_PORT}`, AI-сервис (только внутри Docker).
2. **Учётки.** Пароли демо-пользователей `*@demo.example` лежат в `secrets/hr-*.json` (создаётся `sync-hr`, в git не попадает). Основные: `ml.intern@demo.example` (стажёр ML) и `buddy@demo.example` (наставник).
3. **Чат стажёра на сайте:** войти как `ml.intern@demo.example`, нажать на Бади в правом нижнем углу любой страницы. Это тот же виджет, что в расширении. Страница «Бади · AI» (`/chat`) рассказывает, как поставить расширение.
4. **Расширение.** Собрать с `BACKEND_ORIGIN` вашего backend (см. README), в `chrome://extensions` включить «Режим разработчика» → «Загрузить распакованное» → `apps/extension/dist`. Бади появляется в правом нижнем углу любого сайта, клик по нему или по иконке открывает чат. Войти той же учёткой стажёра.
5. **Кабинет наставника:** во втором окне (инкогнито) войти как `buddy@demo.example`, раздел «Кабинет наставника» (`/mentor`). Обновляется сам каждые 15 секунд.

**Демо-профиль стажёра** берётся из БД: этап, активная задача, задачи на проверке и замечания наставника из чек-листов `ml.intern@demo.example`.

| 3.9 | Быстро отправить больше 20 сообщений за минуту | Сообщение «Слишком много запросов» | C3 |
| 3.10 | Остановить AI: `docker compose -p ai-buddy stop ai`, задать вопрос, затем `start ai` | Понятная ошибка и кнопка «Повторить», панель не зависает | обработка сбоев |

**Резервная локальная модель (A7, по желанию).** Ollama с `qwen3.5:4b` уже стоит. В `.env` прописать:
```dotenv
LLM_FALLBACK_BASE_URL=http://host.docker.internal:11434/v1
LLM_FALLBACK_MODEL=qwen3.5:4b
LLM_FALLBACK_EXTRA_BODY={"reasoning_effort":"none"}
```
Затем:
1. Временно испортить `LLM_BASE_URL`.
2. Пересоздать ai: `docker compose -p ai-buddy up -d ai`.
3. Задать вопрос по базе. Ответит локальная модель (первый раз 10–20 с, пока она загружается). Действия у неё ненадёжны: это известное ограничение, см. `apps/ai/eval/reports/local-models.md`.

## 3a. Персонаж Бади (расширение)

Демо-страницы «рабочих инструментов» лежат на сайте: `http://127.0.0.1:5173/demo/wiki.html`, `/demo/grafana.html`, `/demo/jira.html` (статика из `apps/web/public/demo/`, данные синтетические). На остальных страницах сайта расширение Бади не показывает: там встроенный виджет.

| # | Что сделать | Что должно быть |
|---|---|---|
| 3a.1 | Открыть `/demo/wiki.html` | Справа внизу Бади машет рукой и предлагает сводку (раз в день) |
| 3a.2 | Перетащить Бади мышкой в другой угол, обновить страницу | Остаётся там, куда его поставили |
| 3a.3 | Клик по Бади (или по иконке расширения) | Окно чата рядом с ним; при первом входе за день — бриф. Пока идёт ответ, антенна мигает, рот «говорит» |
| 3a.4 | Выделить жёлтую фразу «Для мержа нужно минимум 2 одобрения» → в пузыре «Это актуально?» | Ответ про противоречие (2 или 1 аппрув) с источниками и датами, предложение спросить наставника |
| 3a.5 | Открыть `/demo/grafana.html`, нажать на пузырь «Подсказать, что смотреть?» | Ответ про дашборды и практическое упражнение, с пометкой «с учётом страницы» |
| 3a.6 | В чате Бади: «Оформи отпуск с 1 по 14 декабря» → «Подтвердить». Затем в кабинете наставника «Согласовать» | Номер заявки в карточке. Через ~20 с Бади радуется: «🎉 Заявка ABS-…: согласована» |

| 3a.7a | Под ответом нажать на источник | Документ открывается в окне Бади (полный режим), процитированный абзац подсвечен. «Открыть документ полностью ↗» ведёт в демо-вики `/wiki/<id>.html` с подсветкой фрагмента. «← К чату» возвращает диалог |
| 3a.8 | Открыть любой другой сайт | Бади там тоже есть. В боковой панели «Убрать» отключает его на этом сайте, «Показать» возвращает |

## 6. Технические проверки

- `docker compose -p ai-buddy exec ai python -c "import urllib.request;print(urllib.request.urlopen('http://127.0.0.1:8001/metrics').read().decode()[:1500])"` — метрики Prometheus.
- `cd apps/ai && python -m eval.run e2e` (или через Docker, см. `apps/ai/eval/README.md`) — полный eval, около $0.1.
- `python -m eval.run e2e --dataset eval/holdout.jsonl` — отложенный набор.
