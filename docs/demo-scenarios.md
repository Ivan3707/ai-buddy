# Демо на 3 минуты

1. Запустить `docker compose -p ai-buddy up --build -d --wait`; открыть веб 127.0.0.1:5173.
2. Показать общий и ML-сценарий. Отметить задачу. Переключить роль backend: профессиональный сценарий изменится, общий останется. Обновить страницу: прогресс исчезнет, это временное демо-состояние.
3. Спросить «Как оформить отпуск?»; показать инструкцию и источник `hr.example.com/leave`. Объяснить, что заявка не создается.
4. Спросить «Как получить доступ?»; показать другой источник. Спросить `xyz`: явный отказ из-за отсутствия знания.
5. Собрать расширение, загрузить `apps/extension/dist` в Chrome и задать тот же вопрос. Ответ идёт через тот же Go Backend.
6. Остановить только AI: `docker compose -p ai-buddy stop ai`. Новый вопрос в вебе/расширении показывает ошибку. Восстановить: `docker compose -p ai-buddy start ai`.

## Автоматические проверки

Unit-тесты проверяют валидацию, retrieval, ошибки AI и фильтрацию ролей. Live contract checker проверяет реальные JSON-ответы. Playwright проверяет веб и загруженный MV3 popup в Chromium. Автоматический тест расширения не заменяет ручную установку в пользовательском Chrome.

Для каждого прогона фиксируйте дату, commit, команды и фактические результаты. Проверки CI видны во вкладке Actions. Полноценное качество RAG/LLM пока не измерено: реальной модели нет.
