# Гид по AI-Buddy: что есть и как всё проверить

Состояние на 14.11.2026. Стенд запущен локально как Docker Compose-проект `aibuddy`. Данные синтетические, это не регламенты Авито.

## 1. Что запущено

| Сервис | Адрес | Что это |
|---|---|---|
| web | http://127.0.0.1:5173 | Основной сайт: React, вход, чек-листы, календарь, заметки, чат |
| backend | http://127.0.0.1:18080 | Go API, единственная точка входа для веба и расширения |
| ai | только внутри Docker (`ai:8001`) | Python: поиск по базе знаний, LLM, агент |
| postgres | `127.0.0.1:5433`, БД `app` | Данные Вани из бэкапа плюс таблицы ассистента (миграция 00002) |
| playground | http://127.0.0.1:18090 | Dev-заменитель бэкенда с данными в памяти, плюс демо-страницы для Бади |

Проверка: `docker compose -p aibuddy --profile playground ps` — у всех сервисов статус `healthy`.

## 4. Сценарии проверки

### А. Стажёр на сайте (5 минут)

1. Войдите как `ml.intern@demo.example`, откройте Главную. Должен быть виден прогресс по общему треку и треку ML.
2. Откройте «Чек-листы». У активной задачи нажмите «Отметить выполненной» или опишите результат и нажмите «Отправить на проверку». Статус сменится, откроется следующая задача. Отправленное на проверку увидит `buddy@demo.example` в «Команде».
3. Создайте событие в «Календаре» и заметку в «Заметках».
4. В «Заявках» запросите доступ к инструменту. Появится тикет со статусом.

### Б. Бот: ответы, противоречия, действия (сайт или расширение, 7 минут)

1. Войдите на сайт как `ml.intern@demo.example` и нажмите на Бади в правом нижнем углу. Или откройте боковую панель расширения. Первой придёт сводка дня с текущим этапом и активной задачей. Сводка приходит раз в день.
   - Сразу после входа виджет может показать подсказки «задача идёт дольше плана». Кнопка «Обсудить с Бади» откроет чат с вопросом по этой задаче.
2. Спросите «Как оформить отгул?». Ответ придёт потоком, со ссылкой на источник и цитатой.
3. Уточните: «а за сколько дней?». Бот сам называет противоречие между документами (2 и 3 рабочих дня) и предлагает уточнить у наставника.
4. Напишите «Хочу отгул 21 ноября». Появится карточка заявки. Нажмите «Подтвердить» и получите номер `ABS-…`.
5. Попросите «Дай мне admin-доступ к grafana». Бэкенд откажет даже после подтверждения: так работает политика прав.
6. Спросите «Есть ли в офисе спортзал?». Бот честно скажет, что не знает, и предложит передать вопрос наставнику. Подтвердите.
7. Поставьте 👍 или 👎 под ответом.

### В. Наставник обрабатывает то, что пришло от бота (сайт, 3 минуты)

1. В отдельном окне (инкогнито) войдите как `buddy@demo.example`. Виджет Бади сразу покажет «есть вопросы стажёров и заявки на согласование».
2. Откройте «Бади · AI», вкладка «Кабинет». Вверху метрики: сколько вопросов бот закрыл сам и сколько минут сэкономил наставнику.
3. В блоке «Вопросы стажёров» нажмите «✦ AI-черновик ответа». Придёт черновик со ссылками и, если в базе пусто, каркас новой статьи. Поправьте его и нажмите «Отправить стажёру».
4. В блоке «Заявки стажёров» нажмите «Согласовать».
5. Вернитесь в окно стажёра. Через ~20 с виджет покажет «🎉 Заявка ABS-…: согласована» и «Наставник ответил на твой вопрос». Ответ появится прямо в диалоге.
6. «Пробелы» и «Линтер» внизу кабинета показывают, где базе знаний не хватает статей и где документы противоречат друг другу.

То же через API (от имени `buddy@demo.example`):
- `GET /api/buddy/questions?status=open` — вопрос стажёра из шага Б6. `GET /api/buddy/questions/{id}/draft` — AI-черновик ответа со ссылками и предложением статьи в базу знаний.
- `GET /api/buddy/requests` — заявка из шага Б4. `POST /api/buddy/requests/{id}/decision {"status":"approved"}` — согласовать её. У стажёра статус сменится в `GET /api/requests`, а Бади покажет «🎉 согласована».
- `GET /api/metrics/chat` — сколько вопросов закрыл бот, сколько ушло наставнику, сэкономленные минуты наставника.

### Г. Бади на страницах (3 минуты)

1. Откройте http://127.0.0.1:18090/demo/wiki. В панели расширения нажмите «Показать».
2. Выделите жёлтую фразу. Бади предложит «Это актуально?». Нажмите и получите ответ о противоречии (1 или 2 одобрения) с источниками.
3. Откройте `/demo/grafana`. Бади сам спросит, подсказать ли, что смотреть.
4. Перетащите Бади мышкой: позиция запомнится.

### Д. Подсказка «застрял на задаче» (фоново)

Если задача активна дольше своей оценки, бэкенд раз в минуту просит AI (`/hint`) дать подсказку по базе знаний. Готовые подсказки отдаёт `GET /api/hints`. Виджет Бади показывает непрочитанные на любой странице. «Понятно» отмечает подсказку прочитанной.

## 5. Перезапуск и обслуживание

```powershell
cd C:\Hackaton\ai-buddy
docker compose -p aibuddy --profile playground ps                           # статус
docker compose -p aibuddy --env-file .env --profile playground up -d --build --wait   # пересобрать после изменений
docker compose -p aibuddy logs -f backend ai                                # логи (тексты чата не логируются)
docker compose -p aibuddy stop                                              # остановить без потери данных
```

- Старый стенд `ai-buddy` остановлен, его данные сохранены. Бэкап старой БД лежит в scratchpad (`db-backup-before-main.sql`).
- В Postgres основного стенда есть БД `app_fresh_sync` — чистая синхронизация HR без данных Вани. Пароли из `secrets` подходят к обеим.
- Нагрузочный стенд Вани (`compose.load.yaml`: Grafana `:13000`, Prometheus `:19090`) — отдельная история. Он тоже занимает порт 18080, поэтому вместе с основным его не запускать.
