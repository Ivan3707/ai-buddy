# SDD-001: локальный skeleton AI-buddy

Статус: базовая реализация. Владелец: команда Hack&Change 2026.

## Цель и границы

Обеспечить независимо разрабатываемые Go Backend, Python AI, React web и MV3 extension с проверяемым сквозным демо. В этом инкременте только retrieval-заглушка, роли, список задач и временные чекбоксы. Вне объёма: реальная LLM, auth, БД, корпоративные интеграции, канбан/Гант и синхронизация.

## Требования и приемка

| ID | Поведение | Проверка |
|---|---|---|
| FR-01 | Вопрос про отпуск даёт ответ и источник example.com | AI unit + live contract + оба UI E2E |
| FR-02 | Неизвестный вопрос не выдумывает ответ | AI unit + web E2E |
| FR-03 | Пустой, слишком длинный или некорректный запрос отклоняется | AI/Go unit + live 400 |
| FR-04 | Недоступность AI возвращает 502 | Go unit (HTTP failure + connection failure) |
| FR-05 | Роль выбирает общий и соответствующий профессиональный сценарий | Go unit + web E2E |
| FR-06 | Отметка задачи видна в текущей вкладке | web E2E |
| NFR-01 | Контракты валидны и чат-схемы совпадают | check_contracts.py |
| NFR-02 | Порты локальные, реальные данные отсутствуют | compose review + data review |

## API и данные

Нормативные схемы: `contracts/*.openapi.json`. Предел message 2000 Unicode code points, пробельная строка запрещена. Backend — JSON errors 400/502, FastAPI — 422. AI mode=mock; при смене режима сначала обновить контракт. `data/kb.json`: id/title/keywords/text/url. `data/onboarding.json`: сценарии с role и tasks. Демо ID не представляют реальных сотрудников.

## Порядок следующей работы

2. Ваня: auth, БД, API прогресса и интеграционные адаптеры с mock-реализациями.
3. Маша + дизайнер: UX, обработка ошибок и нужные представления задач.
4. Согласовать следующий SDD/контракт, добавить проверку приемки и открыть PR.

## Риски

Keyword retrieval не оценивает смысл, лексически похожие вопросы могут давать нерелевантный ответ. Ссылки демонстрационные. Прогресс не сохраняется. Требования из исходного файла хакатона не проверены: файл не предоставлен в текущем задании.
